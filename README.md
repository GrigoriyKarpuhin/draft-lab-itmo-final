## Воспроизведение без модели

Нужны Python 3.10+ и Node.js 18+. Для ноутбука — Jupyter с IPython.

```sh
python3 analysis/analyze.py
python3 report/economy.py
cd draft-lab
node --test *.test.mjs
python3 -m unittest discover -p '*test.py'
```

Для диалога установите Ollama и загрузите `qwen3.5:4b-q4_K_M`, затем запустите `python3 server.py` из `draft-lab`. Подробности — в ноутбуке. Изображения героев не включены; они не нужны для проверки расчётов.

## Ограничения

Учебный локальный прототип. Снимок 49 919 матчей октября 2026 года. Ранняя серия `evaluation/*.json` и `evaluation/v1/` относится к прежним версиям; разговорные эксперименты находятся отдельно в `evaluation/conversation/` и `evaluation/roles/`. Прохождение программных тестов не доказывает правильность игровых рекомендаций. Ошибки понимания вопросов и объяснений сохраняются. Экономика основана на сценарных допущениях, а не на измеренной экономии времени пользователей.
